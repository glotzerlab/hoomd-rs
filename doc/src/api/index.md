# All crates

There are more *hoomd-rs* crates not highlighted in this user guide.
Here are links to the documentation for every *hoomd-rs* crate:

- [hoomd-bevy](../api/hoomd_bevy/index.html): Facilitate visual, interactive simulations.
- [hoomd-gsd](../api/hoomd_gsd/index.html): Read and write GSD files.
- [hoomd-geometry](../api/hoomd_geometry/index.html): Define geometric shapes and operate on them.
- [hoomd-interaction](../api/hoomd_interaction/index.html): Define interaction models and apply them to the system's microstate.
- [hoomd-linear-algebra](../api/hoomd_linear_algebra/index.html): Linear algebra methods used by other *hoomd-rs* crates.
- [hoomd-manifold](../api/hoomd_manifold/index.html): Define points in curved space and operate on them.
- [hoomd-mc](../api/hoomd_mc/index.html): Perform Monte Carlo simulations.
- [hoomd-microstate](../api/hoomd_microstate/index.html): Represent the degrees of freedom in your simulation model.
- [hoomd-rand](../api/hoomd_rand/index.html): Pseudorandom number generation methods used by other *hoomd-rs* crates.
- [hoomd-simulation](../api/hoomd_simulation/index.html): Traits that define the macrostate and the simulation model as a whole.
- [hoomd-spatial](../api/hoomd_spatial/index.html): Spatial data structures for efficient site-site interaction computations.
- [hoomd-utility](../api/hoomd_utility/index.html): Miscellaneous data types used throughout *hoomd-rs*.
- [hoomd-vector](../api/hoomd_vector/index.html): Vector and rotation data types and operations.
